# Sources: UU 14/2008 tentang Keterbukaan Informasi Publik

The provision excerpts used by the model live in [`src/models/uu-14-2008/sources.ts`](../../src/models/uu-14-2008/sources.ts).

**They are currently paraphrases written from memory, all marked `verified: false`.** Before treating any result as meaningful:

1. Get the official text (Lembaran Negara RI Tahun 2008 Nomor 61, via JDIH BPK or peraturan.go.id). Save the PDF or text here, with its URL and retrieval date in this README.
2. For each provision in `sources.ts`, replace the `[Parafrase]` excerpt with the exact wording and set `verified: true`.
3. Run `npm run verify`. The `deadlineText` check fails if a deadline in the model no longer matches the number in the official text, which is the point.
4. If the official text differs from the model's reading, fix the model or record an `interpretation`. Don't silently change it.
